# 门户站点设置

管理员进入 **系统配置 → 门户站点设置**，编辑后点击“保存设置”。门户刷新后会读取最新设置，无需重新构建前端。

## 可维护字段

| 分组 | 字段 | 展示位置 |
| --- | --- | --- |
| 公司信息 | 公司全称、首页标语、首页简短介绍 | 顶部、页脚、首页首屏、关于海隆 |
| 联系方式 | 电话、邮箱、完整地址、工作日时间、周末/节假日说明 | 首页联系区域与弹窗、联系我们、专家库、页脚 |
| 地图 | 高德浏览器 Key、经度、纬度、缩放级别 | 联系我们地图 |
| 地铁 | 显示开关、线路、站点、出口、步行距离，可维护多条线路 | 联系我们交通指引 |
| 公交 | 显示开关、公交线路列表、站点、说明 | 联系我们交通指引 |
| 自驾 | 显示开关、导航搜索名称、停车说明 | 联系我们交通指引 |
| 周边 | 周边地标列表 | 联系我们交通指引 |
| 常见问题 | 问题、回答，可添加或删除 | 联系我们常见问题 |

公司简称、英文名称和分拆地址原先没有展示用途，本次不作为可编辑字段。企业介绍正文、图片、亮点，以及业务范围、企业资质、企业荣誉、重要业绩继续使用各自的内容管理页面。

工作日时间使用完整展示文案，例如“周一至周五 9:00–17:20”，也可以填写“全天开放”；页面不再依赖空格拆分文案。

## 数据存储与默认值

- 正式设置存储在 MySQL `portal_site_settings` 的 `id = 1` 记录，内容为 JSON。
- 后端启动时会执行内嵌迁移 `V20261004_001__portal_site_settings.sql` 和版本字段迁移。部署账号需要已有迁移流程要求的建表与修改表结构权限。
- 首次保存前，API 返回 `BackEnd/HailongConsulting.API/SiteSettingsDefaults.json` 的默认展示内容；首次保存后以数据库为准。升级不会覆盖已保存的设置。
- 门户构建直接引用同一份后端默认 JSON，不再维护第二份展示默认值。启动时优先显示七天内最近一次有效缓存（无缓存时使用默认内容），同时请求站点设置；成功后更新展示。单次请求超时为 3 秒，失败后分别等待 500、1500 毫秒，最多尝试三次。
- 读取和保存响应包含 `version` 与 `updatedAt`。保存必须携带读取时的版本；旧版本返回 HTTP 409，表单会保留，重新加载前提示放弃未保存内容。迁移 `V20261004_002__portal_site_settings_version.sql` 添加数据库并发版本字段。
- 默认文件用于初始化和故障回退，运营修改应通过后台完成。开发人员调整默认值时只修改后端默认 JSON，并重新构建 API 与门户。
- 地图 Key 会提供给浏览器，请使用地图平台允许浏览器使用且已限制网站域名的 Key。数据库密码、JWT 密钥等不属于此设置。

## 静态配置

顶部导航、页脚链接及首页模块组件、启用状态、排列顺序继续保存在 `hailong-protral/config/site-config.json`，修改后需要重新构建门户。页脚的联系方式直接读取统一的 `contact`，无需再维护第二份内容。

门户接口地址继续由门户 `.env.*` 的 `VITE_API_BASE_URL` 配置；此字段是构建配置。

## API 与权限

- `GET /api/config/site-settings`：公开读取展示配置，不需要登录，响应禁止缓存。
- `PUT /api/config/site-settings`：仅 `admin` 角色可保存完整设置；结构、必填文本、长度、列表数量和地图坐标由后端验证。
- 常见问题最多 30 项、地铁线路最多 20 条、公交线路最多 50 条、周边地标最多 30 个。

## 验证

后端接口测试覆盖匿名读取、未登录/普通用户禁止保存、管理员保存后公开读取、重复保存更新同一条记录、无效输入拒绝写入：

```powershell
dotnet test BackEnd/HailongConsulting.API.Tests/HailongConsulting.API.Tests.csproj
```

前端构建分别在 `hailong-admin` 和 `hailong-protral` 中运行 `npm run build`。验收时保存一组新的联系方式，再刷新门户，检查首页、联系我们、专家库和页脚是否一致，并确认导航及首页模块顺序保持原配置。

本次接口验证使用 .NET 8 的 TestServer 和 EF InMemory，7 个测试通过；浏览器使用模拟 API 验证后台保存、各页展示、地图文字转义以及请求失败/缓慢时的默认展示。测试未连接真实 MySQL 或调用真实地图服务，建表迁移需要在发布新版 API 时执行。
