# 使用手册

## 访问与登录

Docker 默认门户地址为 `http://服务器IP:8082`，后台为 `http://服务器IP:8080`；实际地址以部署配置为准。本地开发端口见 [项目 README](../README.md)。

API 在用户表为空时生成 `admin` 和随机密码。获取凭据及首次修改密码的方法见 [初始管理员](../README.md#初始管理员)。菜单按角色显示，管理员可维护用户、企业资料、门户设置和系统配置。

## 门户

### 公告信息

进入“公告信息”，选择政府采购或建设工程，按公告类型、关键词、地区及时间筛选。点击标题查看正文、预算、中标 / 成交金额及附件。金额有原文依据时显示，缺少依据的字段留空。

筛选条件保留在网址中，可复制当前网址分享查询结果。返回列表时可继续浏览；加载失败时使用页面重试入口。

### 资讯中心

“新闻中心”和“政策法规”提供分类、搜索、分页及详情。正文中的图片可预览，已提供的附件可打开或下载。

### 关于海隆

通过企业简介、业务范围、企业资质、重要业绩和企业荣誉栏目查看公司资料。资质展示状态与证书有效期分别处理；资料日期及有效期按原证书内容展示。

### 联系与服务

“联系我们”展示电话、地址、地图、交通和常见问题；首页联系入口提供相同联系方式。

“实用工具”提供费用计算页面，按页面规则选择类型并填写金额。专家库页面提供二维码及嵌入的在线信息表单。

## 后台内容维护

### 公告与资讯

1. 从“公告管理”或“信息发布”进入对应栏目。
2. 新建或编辑记录，填写标题、分类、正文及页面提供的业务字段。
3. 公告分别填写明确预算和最终中标 / 成交金额，单位为万元；没有明确金额时留空。
4. 正文可上传图片，附件字段可上传文件。上传结束后保存。
5. 使用状态字段控制门户展示；保存后刷新门户核对详情。

标题、正文及字段组合由服务器校验。扫描件正文可以图片形式保存。清空已有金额会清除该字段，填写 0 则保存为 0。

### 企业资料

“企业资料”维护简介、业务范围、资质、业绩和荣誉。按真实资料填写图片、编号、日期及有效期；排序数字越小越靠前。缺少可靠依据的字段留空。

### 门户设置

“门户设置”维护公司全称、标语、首页简短介绍、电话、邮箱、地址、营业时间、地图、交通及 FAQ。保存后门户刷新读取，无需重新构建。

完整字段见 [门户设置说明](portal-settings.md)。导航和首页模块的启用 / 顺序由开发配置维护，见 [配置位置](configuration/storage.md)。

### 附件管理

支持上传、预览、查看引用和删除。允许格式及体积以上传组件显示的服务器选项为准。

文件仍被已保存内容引用时不能删除；先移除对应内容中的引用并保存，再重新查询。批量删除中任一文件被引用，整批操作会被拒绝。

## 保存与会话提示

| 提示 | 处理方式 |
| --- | --- |
| 内容已被其他人修改 | 保留当前编辑内容，读取最新版本，合并后保存 |
| 会话失效 | 在提示的新窗口重新登录，再返回当前页面继续编辑 |
| 尚有未保存内容 | 选择继续编辑或确认离开 |
| 上传进行中 | 等待完成再提交 |
| 参数验证失败 | 按字段提示修改 |
| 最后一名管理员保护 | 保留至少一名启用管理员 |

退出登录前会确认未保存内容，并调用服务端注销。

## 系统与统计

管理员可维护用户和区域字典、查询系统日志，用户可修改自己的密码。新密码至少 6 位。

公告数量按记录计数，中标 / 成交金额只汇总已记录结果金额；同一项目可能有多条结果公告。发布时间趋势和创建时间统计使用各自口径，不能直接视为去重项目数量或完整财务总额。
