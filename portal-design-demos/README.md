# 海隆门户 · 四种设计方向

独立静态演示项目，用同一套真实初始化资料比较四种门户版式。无需后端、数据库、npm 安装或外部字体。将整个目录复制到其他位置即可运行。

## 查看效果

直接打开 `index.html` 即可使用。也可以安装 Node.js 18 或更高版本后，在本目录运行：

```powershell
npm run dev
```

访问 http://127.0.0.1:4177，页面顶部可以切换风格。`PORT` 环境变量可修改端口。服务器只监听本机。

```powershell
npm run build
npm run preview
```

构建输出在 `dist/`，可作为纯静态文件托管。文件使用相对路径，也支持直接打开构建后的 `dist/index.html`。

## 设计方向

| 方向 | 视觉与布局 | 适用重点 |
| --- | --- | --- |
| 专业企业蓝 `?style=corporate` | 品牌蓝与冷白，文字和建筑并列首屏，行式公告，六项服务网格 | 企业形象和查询效率兼顾 |
| 建筑编辑风 `?style=editorial` | 暖白、墨绿、陶土色，宋体大标题，左侧建筑，编号服务目录 | 工程行业气质和品牌记忆 |
| 克制极简 `?style=minimal` | 黑白为主，居中标语，建筑全景，细分隔线与较大留白 | 阅读舒适、精确和克制 |
| 公告优先 `?style=portal` | 缩短横幅，公告与服务侧栏并排，提高列表密度 | 高频查询政府采购和工程公告 |

切换改变布局、字体、信息密度及视觉层级。当前风格保存在本机浏览器；网址参数优先于本地保存的选择。

## 对当前门户的设计判断

“AI 化”是一种视觉感受，不能据此判断代码或设计的来源。现有页面中，下列元素叠加后会形成较强的通用模板感：

- 深色渐变首屏、光晕、粒子、渐变标题和胶囊按钮同时出现，缺少工程咨询行业的具体视觉语言。
- 多数模块沿用居中标题、渐变短线、大圆角卡片和悬浮阴影，层级和节奏较单一。
- 首屏占满屏幕，企业介绍又排在公告前，查询公告需要继续滚动。
- 公告采用较大的卡片承载长标题，有限的首屏空间中展示的信息偏少。
- 首页导航及多个并列模块容易分散注意力，需要明确“查公告、了解服务、联系公司”三条主要路径。

本演示以建筑结构、网格、中文排版及公告阅读为设计依据。视觉判断来自当前项目源码和本演示浏览器检查；不代表完成了现有正式门户的全设备审计。

## 内容及交互

- 24 条公告：政府采购与建设工程各 12 条，摘自已复核的初始化数据，资料截止 2026-09-24。
- 6 篇历史资讯与政策资料；保留原发布日期、正文和分类，不将历史政策描述为最新政策。
- 公司简介、标志、电话、地址和邮箱来自现有项目资料。
- 2526 条公告、43 篇资讯为归档数据总量；页面明确标为归档，未将其解释为业绩。
- 建筑图为原创 SVG 插画，不代表公司办公楼或实际承接项目。未补充的荣誉、资质及项目照片没有虚构。
- 支持业务分类、公告类型、标题/地区检索、展开列表、公告正文、预算/成交金额、资讯目录、服务详情及联系信息。
- 风格切换保留筛选；详情采用原生对话框，支持键盘 Escape 关闭；手机布局自动调整；尊重减少动态效果设置。

这是静态设计比较，正文与历史金额仅为当前数据快照。报名、上传文件、后台管理、实时更新等业务需要正式系统支持。

## 文件结构

```text
portal-design-demos/
├── index.html             # 演示工具栏和页面容器
├── styles.css             # 四种布局及响应式规则
├── app.js                 # 本地渲染、切换、筛选和详情
├── data.js                # 经过清理的资料摘录
├── assets/                # 原有标志与原创建筑插画
├── tools/serve.mjs        # Node 原生静态服务器
├── tools/build.mjs        # 独立静态构建
└── package.json
```

`data.js` 不包含数据库连接、门户管理配置或地图密钥；运行时不请求业务 API、CDN 或外部图片。
